**🏠 House Price Prediction App**
A simple web application to predict house prices based on features like area, bedrooms, bathrooms, and amenities. 
Built using Streamlit and a machine learning model trained with regression techniques.

**Features**:
User-friendly UI for inputting house details
Scalable and standardized model for accurate predictions
Visual insights with SHAP for feature importance
**How to Run:**

Clone the repository
Install dependencies: pip install -r requirements.txt
Launch the app: streamlit run app_ui.py
